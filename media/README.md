# Media

Approved diagrams, figures and demonstration media, used in reports, presentations and the project dashboard.

| Folder | Content | Format |
| --- | --- | --- |
| `diagrams/` | Architecture and method diagrams | SVG preferred (PNG otherwise) |
| `figures/` | Result figures selected for reports or the dashboard | SVG or PNG |
| `videos/` | Short demonstration clips | Not committed (see `.gitignore`); store on the shared Drive and link them, or add a small poster image here |

Rules: only approved and real material; file names `<subsystem>_<what>_<YYYY-MM-DD>.<ext>`; keep files small (under about 2 MB each). Raw experiment plots stay in `experiments/`.
